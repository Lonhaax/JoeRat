## ⌨️ Keyboard Shortcuts

### **Productivity Shortcuts**
| Shortcut | Action | Description |
|----------|--------|-------------|
| **F5** | Reconnect | Quick reconnect to server |
| **F11** | Toggle Fullscreen | Enter/exit fullscreen mode |
| **Ctrl+Up** | Quality Up | Increase stream quality |
| **Ctrl+Down** | Quality Down | Decrease stream quality |
| **Ctrl+L** | Toggle Lock | Lock/unlock remote input |
| **Ctrl+Shift+C** | Focus Clipboard | Jump to clipboard input |
| **Ctrl+R** | Refresh Telemetry | Update system metrics |

### **Benefits**
- **Faster workflow** - no more hunting for buttons
- **Professional feel** - like commercial remote desktop tools
- **Accessibility** - keyboard navigation for power users
